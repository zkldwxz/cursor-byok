## 主要更新

### 检索
- 语义检索改为内置工具 `SemanticSearch`，各模式都有，不需要安装扩展。它在代码所在的机器（本机或 SSH 远端）上运行一条固定命令，不逐次询问。
- 一台机器首次使用时，桌面端会把检索程序和模型送过去并校验（约 34MB，只传一次）。支持 macOS 和 Linux；Windows 工作区请用 Grep。
- 描述行为的问法更准：从问句猜出的函数名不再占满结果前排。18 个未参与调整的仓库、180 道题，前五命中由 41 提到 91。
- 可按名字查枚举成员（Rust、TypeScript、Java、C/C++），例如 `Attempt::SharedPrefix`；没有定义的标识符优先返回原样出现的代码。
- 按名字搜函数时，返回的片段从定义那一行开始。以前大函数的签名会并进上一个函数的块里，模型常看到的是隔壁函数。RepoQA 60 道函数名题，前五条里能看到定义的由 42 道提到 59 道。索引格式升级，每个仓库首次搜索时重建一次。
- 在 Cursor 自建的 worktree（`~/.cursor/worktrees/` 下）里，Grep 和 Glob 不再全部返回空。Cursor 的索引版 Grep 会把这些目录里的文件都当成已忽略，现在 Grep 和 Glob 一律用 ripgrep。
- 系统提示词说明何时先用 `SemanticSearch`、Grep、Glob 和 Read。

### 手机遥控（Cnod）
- 手机 App 改名 Cnod，换了自己的图标。
- 对话结束或等你确认时发通知，点通知直接打开那个对话；音效在手机扬声器上听得见。
- 手机上可以设置上下文和思考强度，可以切换电脑、筛选对话列表；配对在重启后保留。
- 显示连接状态（手机到电脑、电脑到 Cursor、模型上游）和上游重试次数，长对话完整显示。
- SSH 工作区的对话可以在手机上查看（只读，发消息仍需在电脑上）。
- 中继可选：BaoCode 公共中继、自建中继或不用中继，默认使用公共中继。
- 关闭再打开遥控、重启 Cursor 后，Cursor 不再显示“未登记”而长时间断开；打开过的对话在列表里保留标题和时间。
- 关闭 Cursor 的自托管云端 worker：它绕过 BYOK，并且为每个工作区常驻进程。

### 浏览器
- 连接 Chrome 不再需要配对，已打开的页面可以加入分组。

### 修复
- Gemini（ACP 桥）的一次生成带出多个工具调用时，后面的调用用量报 0，不再被当成上下文大小，上下文显示和自动压缩不再受影响。
- 每个版本安装自己的检索程序，升级后不会用到旧版本的程序。

需要 Cursor 3.31 或更新版本。工具目录有变化，升级后每个已有对话会重写一次提示词缓存。

## Highlights

- `SemanticSearch` is a built-in tool that runs on the machine holding the code, locally or over SSH, and needs no extension. The program and its model are delivered and verified once per machine. macOS and Linux workspaces only.
- Questions about behavior are answered by the code that implements it: names guessed from the question no longer fill the first results. On 180 held-out questions the first five results now contain the answer 91 times instead of 41.
- Enum members are found by name in Rust, TypeScript, Java, C and C++.
- A search by function name shows the definition itself. A large function's signature used to land in the previous function's chunk, so the model often saw the neighbouring code. On 60 RepoQA name questions the definition is now visible in the first five results 59 times instead of 42. Each repository's index is rebuilt once.
- Grep and Glob find matches in Cursor's own worktrees under `~/.cursor/worktrees`, where Cursor's indexed search treated every file as ignored. Both now always run ripgrep.
- The phone app is now Cnod. It alerts when a conversation finishes or waits for you, sets context and effort, switches computers, shows the state of each link, and reads SSH conversations.
- The relay can be BaoCode's public one, your own, or none.
- Cursor stays connected across restarts and when remote control is turned off and on; Cursor's self-hosted cloud worker, which bypasses BYOK, is turned off.
- Chrome connects without pairing.
- A call that reports zero usage no longer counts as a measurement of the context size.
- Requires Cursor 3.31 or later.
- The tool catalog changed, so each existing conversation rewrites its prompt cache once after upgrading.
