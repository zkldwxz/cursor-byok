## 主要更新

### 费用与缓存
- Claude 提示词缓存改为保留 1 小时，编译、测试等停顿后不必重写整段上下文；不支持 1 小时的网关会退回 5 分钟。
- 压缩上下文时沿用原对话的提示词、工具和历史，直接读取已有缓存。此前每次压缩会把整段上下文重写一遍（实测 83–92 万 token）。
- 压缩被拒绝或模型误调工具时，会换一种方式重新总结，不再直接丢掉历史。
- 按模型和渠道计价，未填写的单价用 models.dev 的公开价格补上。

### 模型与供应商
- 新增 Magpie 本地网关供应商，启动时及每 10 分钟同步模型。
- 供应商改为独立页面，模型可排序、可测试；移除内置的 Codex、Antigravity、Grok 和 ZCode 插件。
- 支持图片识别设置：不支持图片的模型可交给其他模型看图。

### Cursor 能力
- 浏览器 DevTools：连接 Chrome 操作网页，配对在重启后保留。
- 手机遥控：在手机上查看 Cursor Agents Window 的对话、发消息、切换模式和模型、批准操作。安卓安装包不在本次附件里。
- 网页搜索改用 Exa 公开服务。
- 工作区扩展内置语义检索程序（macOS、Linux、Windows）。Cursor 3.32.4 的 Agents Window 会拦截它，编辑器窗口不拦截。

### 界面
- 调用记录改为可就地展开的列表，显示 token 构成和时间线。
- 重做首页概览、计价和插件页，图标跟随深浅色主题。

### 稳定性
- 修复重发消息后运行失败（“stable history shrank”）和历史分支重复占用空间。
- 限制数据库日志体积，定期清理无用历史。
- 模型请求失败时按指数退避重试，额度耗尽不再反复重试；连接 30 秒超时。
- 修复后台子代理完成后不结束的问题。

## Highlights

- The Claude prompt cache is kept for one hour, with a five minute fallback for gateways that reject it.
- Context compaction reads the conversation's cached prefix instead of writing the whole context again, and no longer drops the history when the first summary attempt fails.
- Calls are priced per model and channel, with models.dev filling unset prices.
- Magpie gateway provider, per-provider pages, and vision delegation for text-only models.
- Browser DevTools with a persistent Chrome pairing, and phone remote control for the Agents Window (the Android package is not attached).
- Web search through Exa, and a workspace extension that bundles semantic search.
- Reworked call list, overview and pricing pages.
- Fixes for retried inputs, duplicated history, database growth, retries and stuck background subagents.
